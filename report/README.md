# Report

Put the report PDF here, named `report.pdf` (or `Lastname_ECON5200_Replication.pdf`).

- 12 pages maximum; 8 to 10 is typical.
- Section 1 (Positioning) is two pages maximum.
- Every number, table and figure in the report must come from `python reproduce.py`. Save
  figures and tables to `output/` from the notebooks and use those files, so the report and
  the code cannot drift apart.
- The headline number in the report must match the one in the top-level `README.md` and in
  `output/headline_table.csv`.
